# Kaitlyn Hu — portfolio site

Personal portfolio for finance recruiters: Home, About, Projects, Résumé, Contact.
Built Oct 29, 2026 (RESECON 490AI, In-Class 16) from the Oct 27 version in `website_lab/kaitlyn-hu/`.

## Open it
Double-click `index.html` in Finder. No install or build step.

## Publish (GitHub Pages)
Upload everything inside this folder (not the folder itself) to the repository `USERNAME.github.io`, so `index.html` sits at the top.

## What is real vs. placeholder
- Real: everything taken from Kaitlyn's résumé, the headshot (`photo.jpg`), email and LinkedIn.
- Placeholder: every item that starts with `[PLACEHOLDER]` (GitHub link, project summary, report/slides/charts links). Search the folder for `[PLACEHOLDER]` to find them.
- Résumé PDF: not included yet ("coming soon"); the current PDF lists a GPA, which today's privacy rules leave off the site.
- Privacy: no phone number, home address, student ID, GPA or transcript.
